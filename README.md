# comparar-modelos-spectheart
Comparação de SBART, BART, Random Forest e XGBoost na classificação de dados SPECT Heart.
# Informações
Este repositório reúne os dados utilizados no estudo, os códigos desenvolvidos para as análises, os dados simulados, os gráficos apresentados no relatório e o relatório final, contendo informações sobre a metodologia, os resultados e as conclusões da pesquisa.
